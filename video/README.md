# 영상 자산

| 파일 | 용도 |
|---|---|
| `captions.srt` | 구간 타이틀 자막. 편집 프로그램에 그대로 불러옵니다 |

## 자막 불러오기

SRT는 표준 형식이라 어느 편집기에서나 열립니다.

| 편집기 | 경로 |
|---|---|
| DaVinci Resolve | 미디어 풀에 드래그 → 타임라인 자막 트랙에 올리기 |
| Premiere Pro | File → Import → 캡션 트랙으로 배치 |
| Final Cut Pro | File → Import → Captions |
| YouTube | 업로드 후 자막 → 파일 업로드 |

## 타임코드는 예상치입니다

편집 후 약 11분 기준으로 잡은 값입니다. **러프컷이 끝나면 실제 컷 길이에 맞춰
밀어야 합니다.** 대부분의 편집기에서 자막 클립을 통째로 선택해 옮기거나, 구간별로
나눠 스냅할 수 있습니다.

순서와 문구는 [06-영상-편집-가이드.md](../06-영상-편집-가이드.md)의 샷 리스트와
대응합니다. 샷을 빼거나 더하면 자막도 함께 고치세요.
